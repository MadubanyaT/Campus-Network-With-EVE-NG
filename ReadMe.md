# Campus Network 


## Project Overview
This project documents the progressive design and implementation of a simulated campus network topology using ***EVE-NG***. The network is developed incrementally, with each phase introducing new devices, protocols, services, and design improvements.

The end-goal is to demonstrate not only the final solution but also the reasoning behind each design decision, reflecting how real-world networks evolve over time.

## Objectives
- Build a campus network from a small initial topology.
- Introduce enterprise networking concepts gradually.
- Improve the network architecture at each phase.
- Document every design decisions and technology choices.
- Follow industry-standard network design principles.
