# Initial Campus Network Topology

## Description

This phase is about a newly established university that has only one building and a small number of employees. At this stage, the priority is simply to provide basic connectivity between departments. Future expansion is expected, therefore the network is built with scalability in mind.

## Notes
- Parent Network: 172.16.0.0/16
- 8 - 10 Departments are expected including students.
- Subnetting for the network can be found on this document [Campus Network Subnetting](./Subnetting.docx)
- This phase will focus only on two departments (Finance and ICT)
